# 专升本英语 - 安徽省专升本单词学习应用

1106 个专升本高频词汇，40 个单元，支持发音、测验、考试、打卡统计。

## 功能

- 📖 单词学习：音标、释义、例句、发音
- ✏️ 单词测验：英译中 / 中译英
- 📊 学习统计：打卡日历、错题本、连续天数
- 📝 模拟考试：40 题 30 分钟
- 📱 手机优化：PWA 可添加到主屏幕

## 本地运行

```bash
pip install -r requirements.txt
python app.py
```

访问 http://127.0.0.1:8849

## 部署

已配置 Render 部署文件（`render.yaml`）。
